## Sobre o projeto

O Neural Rose é uma plataforma que transforma dados de fornecedores em inteligência para compras, compliance, gestão de terceiros e tomada de decisão. A proposta é antecipar riscos antes que afetem contratos, reputação ou continuidade operacional.

## Funcionalidades

- Dashboard executivo
- Análise cadastral de fornecedores
- Score de risco
- Projeção de risco futuro
- Alertas preventivos
- Ranking de fornecedores
- Simulador de cenários *What-If*
- Assistente para investigação
- Análise de risco cibernético
- Recomendações executivas

## Módulos

| Módulo | Finalidade |
|---|---|
| Digital Twin | Visão consolidada do fornecedor |
| Future Risk Engine | Projeção de risco e confiança |
| Neural Investigator | Explicação e investigação dos sinais |
| What-If Simulator | Simulação do impacto de eventos |
| Sentinel Agent | Monitoramento e alertas contínuos |

## Tecnologias

HTML5, CSS3, JavaScript, Tailwind CSS, Chart.js, conceitos de análise preditiva, UX/UI, gestão de riscos e compliance.
