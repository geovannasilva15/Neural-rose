# 🌹 Neural Rose | IA Preditiva para Análise de Fornecedores

🏆 **2º lugar no Hackathon WeHandle x PUC Campinas 2026**

O **Neural Rose** é uma plataforma de Inteligência Artificial criada para prever riscos em fornecedores antes que eles impactem a operação de uma empresa.

A solução combina análise de dados, score de risco, alertas inteligentes, simulações de cenário e recomendações executivas para apoiar áreas como compras, compliance, gestão de terceiros e tomada de decisão estratégica.

---

## 🚀 Demonstração

Este projeto é uma aplicação web estática.

Para visualizar localmente, abra o arquivo:

```txt
index.html
```

Ou publique pelo **GitHub Pages** para gerar um link online do projeto.

---

## 🎯 Objetivo

Transformar dados de fornecedores em inteligência preditiva, permitindo que empresas identifiquem riscos futuros de forma preventiva, e não apenas reativa.

---

## 🧠 Como funciona

```txt
CNPJ
↓
Coleta de Dados
↓
Análise de IA
↓
Score Atual
↓
Previsão de Risco
↓
Alertas
↓
Recomendações
```

---

## 📊 Funcionalidades

- Dashboard executivo de fornecedores;
- Análise de CNPJ;
- Score de risco de 0 a 100;
- Previsão de risco futuro;
- Alertas preventivos;
- Simulador What-If;
- Ranking de fornecedores;
- Assistente de IA para investigação;
- Análise de Cyber Risk;
- Recomendações para tomada de decisão.

---

## 🧩 Módulos do projeto

### Dashboard
Visão geral dos fornecedores, indicadores principais, alertas e evolução de score.

### Digital Twin
Ficha completa do fornecedor com dados cadastrais, score e análise por eixo.

### Future Risk Engine
Motor de previsão de risco futuro com projeção de score e confiança da análise.

### Neural Investigator
Assistente de IA para investigação e explicação dos riscos do fornecedor.

### What-If Simulator
Simulador de cenários para entender o impacto de eventos no score do fornecedor.

### Sentinel Agent
Monitoramento contínuo de sinais comportamentais, alertas e recomendações.

---

## 💡 Diferencial

Enquanto soluções tradicionais mostram apenas o estado atual do fornecedor, o **Neural Rose** busca antecipar riscos antes que eles impactem contratos, operação, compliance ou continuidade do negócio.
